# Проект V2 — портал швейного цеха и склада

Сервер на чистом Python (stdlib), рабочие данные — в Excel-книге (`.xlsm`), опционально зеркало в SQLite.
Модули: цех (заказ → конструктор → снабжение → технолог → крой → пошив → упаковка → зарплата),
склад, Wildberries (FBS), магазин. Веб + Android + iOS (PWA).

## Запуск
Один раз: `pip install -r requirements.txt` (нужны lxml и openpyxl).
```
python3 server.py --port 8787
```
Windows: `start.bat`, macOS: `start.command`. Тесты: `python3 -m pytest -q tests`.

## Рабочая книга цеха
`workbook/цех_склад для apk.xlsm` — эталон книги заказчика (база цеха), `docs/процессы_цеха.xlsx` — его схема процессов.
Если путь к книге не задан (`data/цех_источник.txt`), сервер сам делает копию эталона в `data/` и пишет в неё,
сам файл в `workbook/` не меняется. Так же `workbook/portal.db` — эталон SQL-базы (заказы WB, товары, закупки): пока своей базы нет, сервер берёт её копию.
Токены WB в репозиторий не кладутся: их вносят на сайте в настройках кабинетов, они сохраняются в `secrets/` вне git.
**Репозиторий должен оставаться приватным**: в книге данные цеха
и тестовые пароли `123456`. Перед открытием репозитория убрать книгу из истории git.

## Заказы Wildberries
Сервер сам забирает новые заказы FBS раз в 5 минут (`config.json → wb_autosync_minutes`, `0` — выключить).
После подтверждения сборки в разделе «Заказы WB» печатаются стикеры WB (58×40 / 40×30, или ZPL для термопринтера).
Заказы магазина и FBS видны одним списком: `GET /api/orders/all`. Подробности — `docs/ТЗ_Заказы_FBS_FBO_Магазин.md`.

## Посмотреть без рабочей книги заказчика (демо)
```
python3 seed.py        # демо-пользователи (компания Ц-01, boss / 123456)
python3 demo_cex.py    # маленькая демо-книга с выдуманными заказами, нормами и складом
python3 server.py --port 8787
```
Открыть `/cex/`. Вернуться на рабочую книгу: `python3 demo_cex.py --back`.
В GitHub Codespaces: вкладка «Порты» → значок глобуса у порта 8787.

## Что НЕ хранится в git (см. `.gitignore`)
- `data/`, `backups/`, `master/` и все `*.xlsm` — рабочие данные заказчика и бэкапы;
- `secrets/wb_tokens.json` — токены Wildberries;
- `keystore.jks` — ключ подписи Android; `*.apk` и `build/` — сборки.

Положите их рядом вручную на каждом компьютере. Пароли по умолчанию (`123456`) смените перед запуском в работу.
