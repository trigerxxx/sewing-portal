# Настройка сканера Zebra TC15 (DataWedge)

Приложение получает сканы двумя способами — выбери один. Рекомендую **Intent** (самый надёжный).

## Шаг 1 — обнови приложение

Установи новый APK (версия 3.0):

| Приложение | Файл | Пакет |
|---|---|---|
| Швейный цех | `android/Проект-V2-цех.apk` | `com.projectv2.ceh` |
| Склад | `android-sklad/Склад-V2.apk` | `com.projectv2.sklad` |

Подпись та же — поставится поверх старого, данные сохранятся.

## Шаг 2 — DataWedge: способ «Intent» (рекомендую)

1. Открой приложение **DataWedge** на TC15.
2. Создай профиль (или открой Profile0):
   - Имя: `Цех`
   - **Associated apps** → добавить приложение → выбрать `Швейный цех` (или `Склад`) → `MainActivity`.
3. В профиле включи:
   - **Barcode input** → включено (ENABLED).
   - **Keystroke output** → ВЫКЛЮЧЕНО.
   - **Intent output** → ВКЛЮЧЕНО:
     - Intent action: `com.symbol.datawedge.api.RESULT_ACTION`
     - Intent category: `android.intent.category.DEFAULT`
     - Intent delivery: **Broadcast intent**
     - (extras оставь по умолчанию — данные уходят в `com.symbol.datawedge.data_string`).
4. Сохрани профиль, включи его (Enabled).

Теперь при сканировании Java-часть приложения ловит Intent и сразу передаёт данные
в экран сборки — клавиатура и фокус полей вообще не участвуют.

## Шаг 3 — альтернатива: «Keystroke» (если хочешь как клавиатуру)

1. В том же профиле DataWedge:
   - **Keystroke output** → ENABLED.
   - **Intent output** → DISABLED.
2. Настрой:
   - Key event code: `13` (Enter) — можно, но не обязательно.
   - Inter-character delay: `0`.
   - Suffix: Enter.

Приложение само собирает символы: пауза 120 мс или Enter — и код уходит в проверку.

## Проверка

Открой «Поставка» → «Собрать заказ». Внизу окна строка:

- `Сканер: ожидание` — сканы ещё не пришли.
- `Сканер: принято 13 симв.` — символы доходят (Keystroke) — дальше всё сработает.
- `Сканер: 2044037812128` — код принят и пошёл в проверку.

Если при Intent-способе строка не меняется, но штрихкод пикает —
проверь, что профиль привязан именно к нашему приложению, а не к браузеру.

## Частая причина «не берёт»

Раньше приложение было версии без встроенного интерфейса — поэтому часть кода
сборки вообще не попадала на телефон. Версия 3.0 собирает интерфейс внутрь APK
и перестаёт зависеть от кэша браузера.
