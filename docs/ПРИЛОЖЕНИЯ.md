## Android

Сборка без Gradle: `aapt2 → javac → d8 → zipalign → apksigner`.

```bash
cd "Проект V2/android"        && bash build_apk.sh   # Швейный цех
cd "Проект V2/android-sklad"  && bash build_apk.sh   # Склад
```

| Параметр | Швейный цех | Склад |
|---|---|---|
| Пакет | `com.projectv2.ceh` | `com.projectv2.sklad` |
| Название | Швейный цех | Склад |
| Адрес по умолчанию | `http://192.168.0.104:8787` | `http://192.168.0.104:8787/sklad` |
| Подпись | `android/keystore.jks` (пароль `ceh2026`) | та же |
| Версия | 2.0 | 2.0 |
| Интерфейс | **внутри APK** (assets/www) | **внутри APK** |

Оба APK ставятся рядом: разные пакеты, разные иконки, не конфликтуют.

### Что изменилось в версии 2.0

Интерфейс (HTML, стили, скрипты, иконки) теперь **встроен в APK** и не скачивается с сервера:

- приложение открывается мгновенно, даже если сервер медленный или недоступен;
- по сети идут только запросы к `/api/` — данные;
- размер APK вырос с 45 КБ до 218 КБ (это те самые ~300 КБ интерфейса);
- обновление интерфейса теперь требует новой сборки APK, а данные обновляются сами.

Как это работает: WebView перехватывает запросы к своему серверу и подменяет
`/`, `/sklad`, `/static/*`, `/sw.js`, манифесты на файлы из `assets/www`;
запросы `/api/*` уходят в сеть как обычно.

**Установка:** скинуть APK на телефон → открыть → разрешить установку из этого источника.

**Смена адреса:** ⚙ в правом верхнем углу → «Найти в сети» или вписать вручную.

## iOS

Отдельного `.ipa` нет и без Apple Developer Account его не установить на iPhone.
Рабочий способ — **PWA**: сайт добавляется на экран «Домой» и открывается без адресной строки,
как обычное приложение.

1. Открыть в **Safari** (именно Safari, не Chrome):
   - всё приложение: `http://192.168.0.104:8787/`
   - только склад: `http://192.168.0.104:8787/sklad`
2. Нажать **«Поделиться»** (квадрат со стрелкой).
3. Выбрать **«На экран Домой»** → «Добавить».
4. Появится иконка с названием «Цех V2» или «Склад».

Что работает в PWA:
- полноэкранный режим без браузерной обвязки;
- своя иконка и имя;
- офлайн-склад (service worker + снимок данных);
- жесты и нижняя панель как в Android-версии.

Чего нет:
- push-уведомлений (iOS требует подписанное приложение и Apple Developer);
- установки «в один клик» из файла — только через Safari.

## iOS без платного аккаунта — варианты

| Способ | Цена | Срок | Что нужно |
|---|---|---|---|
| PWA «На экран Домой» | 0 | бессрочно | Safari |
| Xcode + бесплатный Apple ID | 0 | 7 дней, затем пересборка | Xcode (~10 ГБ) + кабель |
| AltStore / SideStore / Sideloadly | 0 | 7 дней, авто-обновление | Mac/ПК + Apple ID + `.ipa` |
| TestFlight | $99/год | 90 дней | платный аккаунт |
| Ad Hoc / Enterprise | $99/год | 1 год | платный аккаунт + UDID |

Нативный проект уже лежит в `ios/` (SwiftUI + WKWebView, синтаксис проверен).
Инструкция: `ios/README.md`. Для сборки нужен Xcode — на этом MacBook он пока не установлен.

Если нужен настоящий `.ipa` — потребуется Apple Developer Account ($99/год) и Mac с Xcode;
тогда собирается WKWebView-обёртка, аналогичная Android-версии.
