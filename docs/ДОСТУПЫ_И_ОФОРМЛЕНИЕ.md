# Сотрудники, вход и оформление

Обновлено 22.10.2026

## 1. Демо-входов больше нет

На экране входа остались только поля «Логин» и «Пароль». Кнопки демо-доступов убраны.

## 2. Учётки берутся из Excel — лист «сотрудники»

Логины, пароли, роли и активность читаются из рабочей книги
(`цех_склад для apk.xlsm` → лист **«сотрудники»**).

| Колонка | Что писать |
|---|---|
| A — логин | латиницей, без пробелов: `boss`, `sklad`, `zhsk` |
| B — пароль | сам пароль (например `123456`) |
| C — ФИО | имя, которое видно в интерфейсе |
| D — роль | код: `admin`, `manager`, `accountant`, `technologist`, `storekeeper`, `user`, `client` |
| E — должность | подпись (можно оставить) |
| F — цех | код цеха: `Ц-01` |
| G — ставка за час | число |
| H — активен | `да` или `нет` |

Правила:
- **пароль в колонке B** — обычный текст; приложение сравнивает его напрямую;
- если в B стоит `изменён`, пароль берётся из внутренней базы (старый вариант) —
  лучше вписать реальный пароль;
- **`активен = нет`** — вход запрещён, остальные данные сохраняются;
- после правки листа **сохраните книгу** — изменения применятся при следующем входе;
- приложение этот лист **не перезаписывает**, ваши правки не теряются.

Роли и что они видят:

| Код | Роль | Доступ |
|---|---|---|
| `admin` | Начальник | всё |
| `manager` | Менеджер | партии, склад, магазин, сотрудники |
| `accountant` | Бухгалтер | зарплата, отчёты, склад (просмотр) |
| `technologist` | Технолог | партии, склад (просмотр) |
| `storekeeper` | Складчик | склад, приход, адрес, поставки |
| `user` | Швея | задачи, выработка, магазин |
| `client` | Клиент | только магазин и свои заказы |

## 3. Название компании и логотип

Хранятся в листе **«настройки»** рабочей книги:

| A — параметр | B — значение |
|---|---|
| `название` | Швейный цех |
| `подзаголовок` | Бишкек · Ц-01 |
| `логотип` | имя файла, например `logo.png` |

Менять можно двумя способами.

### Способ 1 — в приложении (проще)

1. Войти начальником.
2. Раздел **«Сотрудники» → блок «Оформление»**.
3. Вписать название и подзаголовок.
4. Выбрать файл логотипа → **«Сохранить оформление»**.

Логотип сразу появится на экране входа и в меню.

### Способ 2 — в Excel

1. Открыть лист **«настройки»**, изменить значения, сохранить книгу.
2. Если меняете логотип — положите файл картинки в папку
   `Проект V2/static/` и укажите его имя в ячейке B4 (например `logo.png`).

## 4. Требования к логотипу

| Параметр | Значение |
|---|---|
| Форматы | PNG, JPG, WEBP, SVG |
| Размер файла | до 2 МБ |
| Размер картинки | квадратная, лучше 512×512 |
| Фон | прозрачный PNG — выглядит аккуратнее |
| Куда попадает при загрузке через приложение | `Проект V2/static/logo.<расширение>` |

Если логотип не задан, показывается знак **V2**.

## 5. Если вход не работает

1. Проверьте, что в листе «сотрудники» есть строка с нужным логином.
2. Колонка **H** должна быть `да`.
3. Колонка **F** должна совпадать с выбранным цехом (`Ц-01`).
4. Сохраните книгу — открытая в Excel книга не даёт приложению читать изменения.
5. Пароль — без пробелов в начале и конце.
