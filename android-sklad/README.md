# Android-приложение «Швейный цех»

Обёртка вокруг **существующего** сайта: тот же сервер на MacBook, та же база Excel,
та же бизнес-логика. Приложение ничего не дублирует — оно открывает портал
(`http://<IP-Mac>:8787`) в WebView и адаптирует поведение под телефон
(кнопка «назад», загрузка отчётов, ошибки сети, настройка адреса).

- Пакет: `com.projectv2.ceh`
- Минимальная версия Android: 7.0 (API 24)
- Размер APK: ~150–200 КБ
- Разрешения: `INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE`

## Что умеет

| Возможность | Как реализовано |
|---|---|
| Открывает ваш портал | WebView + Cookies (сессия сохраняется между запусками) |
| Кнопка «Назад» | Возврат по истории сайта; двойное нажатие — выход |
| Адрес сервера | Хранится в настройках приложения (⚙), менять без пересборки |
| Поиск сервера в сети | Кнопка «Найти в сети» перебирает адреса подсети и ищет `/api/companies` |
| Нет связи с Mac | Экран «Сервер недоступен» с кнопками «Повторить» и «Изменить адрес» |
| Пропал Wi-Fi | Красная полоса сверху; при возврате сети страница перезагружается |
| Скачивание отчёта | Файл `.xlsx` уходит в «Загрузки» через DownloadManager (с cookie сессии) |
| Внешние ссылки | Открываются в браузере, а не внутри приложения |

## Установка APK на телефон

1. Скопируйте `Проект-V2-цех.apk` на телефон (кабель, Google Drive, Telegram «Избранное»).
2. Откройте файл в файловом менеджере.
3. Разрешите установку из этого источника, если Android спросит.
4. Запустите «Швейный цех».

Приложение подписано самоподписанным ключом — для личной установки этого достаточно.

## Первый запуск

По умолчанию адрес — `http://192.168.0.104:8787`. Если Mac получил другой IP:

1. Нажмите **⚙** в правом верхнем углу.
2. Нажмите **«Найти в сети»** — приложение просканирует подсеть и подставит адрес.
3. Либо впишите вручную: `http://192.168.0.хх:8787`.
4. **«Сохранить и открыть»**.

Кнопка **«Проверить связь»** покажет, отвечает ли сервер, до сохранения.

## Как узнать IP MacBook

- Системные настройки → **Wi-Fi** → «Подробнее» → **IP-адрес** (например, `192.168.0.104`).
- Или в терминале:

```bash
ipconfig getifaddr en0
```

## Запуск сервера (на Mac)

```bash
cd ~/Desktop/"Проект V2"
python3 server.py --host 0.0.0.0 --port 8787
```

Или двойной клик по `start.command` — он уже запускает с `--host 0.0.0.0` и печатает:

```
Проект V2.1 · http://0.0.0.0:8787
С телефона в Wi-Fi: http://192.168.0.104:8787
```

`--host 0.0.0.0` обязателен: с `127.0.0.1` сервер доступен только самому Mac.

## Чтобы Mac не засыпал

```bash
caffeinate -dimsu          # пока открыт терминал
```

Или: Системные настройки → Аккумулятор → «Предотвращать автоматический сон при
подключении к сети». Для постоянной работы добавьте `caffeinate -dimsu &` в запуск.

## Сборка APK после изменений

Нужны JDK 17 и Android SDK (build-tools 34, platform android-34). На этом Mac они
лежат в `~/.android-build`.

```bash
cd ~/Desktop/"Проект V2"/android
./build_apk.sh
```

Скрипт собирает APK без Gradle: `aapt2 → javac → d8 → zipalign → apksigner`.
Результат: `android/Проект-V2-цех.apk`.

Если ставите Android Studio — можно открыть папку `android/` как проект, но
`build_apk.sh` быстрее и не требует Gradle.

### Ключ подписи

`keystore.jks` создаётся один раз при первой сборке (пароль `ceh2026`).
Храните его: обновления приложения должны быть подписаны тем же ключом,
иначе Android не даст установить новую версию поверх старой.

## Что менять в приложении

| Задача | Файл |
|---|---|
| Адрес по умолчанию | `java/com/projectv2/ceh/AppConfig.java` → `DEFAULT_URL` |
| Верхняя панель, обработка ошибок | `MainActivity.java` |
| Экран настроек и поиск сервера | `SettingsActivity.java`, `Discovery.java` |
| Название, цвета, иконка | `res/values/strings.xml`, `res/values/colors.xml`, `res/mipmap-*` |
| Разрешение HTTP внутри сети | `res/xml/network_security_config.xml` |

## Ограничения

- Работает только в локальной сети (Wi-Fi). Из интернета — нужен туннель и HTTPS.
- HTTP без шифрования: трафик видно внутри вашей Wi-Fi. Для цеха допустимо,
  для публичного доступа — нет.
- Приложение не хранит данные у себя: всё на Mac. Без сервера оно показывает
  экран «Сервер недоступен».
- Несколько телефонов работают одновременно; данные общие, потому что сервер один.
