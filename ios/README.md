# iOS-приложение «Цех V2» (WKWebView)

Оболочка вокруг того же портала, что и Android-версия: тот же сервер, те же данные,
дополнительный код только для окна, настроек адреса и офлайн-экрана.

Состояние: **исходники готовы и синтаксически проверены** (`swiftc -parse` — без ошибок).
Собрать и проверить на устройстве здесь нельзя: на этом MacBook не установлен Xcode.

## Варианты установки на iPhone без платного аккаунта

| Способ | Цена | Срок жизни | Что нужно |
|---|---|---|---|
| **PWA «На экран Домой»** (уже работает) | 0 | постоянно | Safari, 3 нажатия |
| **Xcode + бесплатный Apple ID** | 0 | **7 дней**, потом пересобрать | Xcode (App Store, ~10 ГБ), кабель |
| **AltStore / SideStore / Sideloadly** | 0 | 7 дней, авто-обновление | ПК/Mac + Apple ID + готовый `.ipa` |
| **TestFlight** | $99/год | 90 дней | платный аккаунт разработчика |
| **Ad Hoc / Enterprise** | $99/год | год | платный аккаунт + UDID |

Вывод: без оплаты реально работают первые три. Причём PWA не истекает и не требует Mac —
для ежедневной работы этого достаточно.

## Сборка через Xcode (бесплатный Apple ID)

1. Установить **Xcode** из App Store (бесплатно), открыть один раз, принять лицензию.
2. Установить XcodeGen (или создать проект вручную, см. ниже):
   ```bash
   brew install xcodegen
   cd "Проект V2/ios"
   xcodegen generate
   open CehV2.xcodeproj
   ```
3. В Xcode: **Signing & Capabilities** →
   - Team: ваш Apple ID (Add Account → Apple ID, бесплатный «Personal Team»);
   - Bundle Identifier: `com.projectv2.cehios` (можно добавить свои буквы, если занят).
4. Подключить iPhone кабелем, выбрать его в схеме, нажать **Run**.
5. На телефоне: **Настройки → Основные → VPN и управление устройством** → доверять разработчику.
6. Приложение установлено. Через 7 дней сборка перестаёт запускаться — подключить кабель и нажать Run снова
   (данные и настройки сохраняются).

Бесплатный аккаунт ограничивает: 7 дней на сборку, максимум 3 приложения, 10 App ID.

## Сборка вручную (без XcodeGen)

1. Xcode → **File → New → Project → iOS → App**, имя `CehV2`, интерфейс **SwiftUI**.
2. Удалить созданные `ContentView.swift` и `CehV2App.swift`.
3. Перетащить в проект файлы из `ios/Sources/`.
4. Заменить `Info.plist` содержимым `ios/Info.plist` (или добавить ключи:
   `NSAllowsLocalNetworking`, `NSAllowsArbitraryLoads`, `NSLocalNetworkUsageDescription`).
5. Signing → своя команда → Run.

## Что внутри

| Файл | Назначение |
|---|---|
| `Sources/PortalApp.swift` | точка входа, экран ошибки, повтор, настройки |
| `Sources/WebView.swift` | WKWebView: прогресс, обработка ошибок, свайп «назад» |
| `Sources/SettingsView.swift` | адрес сервера, проверка связи, режим «только склад» |
| `Sources/AppConfig.swift` | хранение адреса и режима в UserDefaults |
| `Info.plist` | разрешения локальной сети и HTTP |

По умолчанию открывается `http://192.168.0.104:8787`.
Переключатель «Только склад» меняет адрес на `/sklad` — приложение показывает только склад.

## Сборка для симулятора (без подписи)

```bash
cd "Проект V2/ios"
xcodebuild -project CehV2.xcodeproj -scheme CehV2 \
  -sdk iphonesimulator -destination 'platform=iOS Simulator,name=iPhone 15' build
```

Симулятор не требует Apple ID — удобно для проверки интерфейса.
